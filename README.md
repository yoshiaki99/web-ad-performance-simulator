# ウェブ広告パフォーマンスシミュレーター

広告予算・クリック単価（CPC）・コンバージョン率（CVR）・顧客単価・原価／変動費を入力し、クリック数、コンバージョン数、売上、利益、CPA、ROASなどを試算するWebアプリです。

## 主な機能

- 入力に連動したリアルタイム試算
- 控えめ・標準・強気のシナリオ比較
- 計算の詳細表示
- ブラウザ内での一時保存と、名前付き保存・読み込み・複製・削除
- スマートフォン対応

保存データはブラウザ内にだけ保存され、外部サーバーへは送信されません。

## ローカルでの起動

```bash
cd prototype
npm ci
npm run dev
```

## 使い分け

- **Web版**：GitHub PagesのURLをブラウザで開いて使います。入力内容と名前付き保存はブラウザ内に保存されます。
- **オフライン版**：`offline/ウェブ広告パフォーマンスシミュレーター_オフライン版.html`をFinderから開いて使います。保存・復元にはJSONファイルを使います。

## オフライン版を作り直す

`prototype`で次を実行すると、`offline/ウェブ広告パフォーマンスシミュレーター_オフライン版.html`を作成します。

```bash
npm run build:offline
```

このHTMLはFinderから開けます。保存はJSONファイルとしてダウンロードされ、次回は画面上の「JSONを読み込む」から復元します。外部サーバーへの送信は行いません。

## 公開

`main` ブランチへのプッシュで、GitHub Pagesが自動的に更新されます。
